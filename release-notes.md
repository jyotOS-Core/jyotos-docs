This page documents key version releases, documentation scope, known limitations, and planned enhancements as the Help Center evolves to support the institutional ecosystem.

***

## Internal Preview v0.1 (Current Release)

**Release Date:** 05 August 2026\
**Status:** 🟢 Active Internal Preview

### Purpose of This Release

The **Internal Preview v0.1** release establishes the foundational structure, user guides, and design standards of the JyotOS Help Center for internal evaluation across Amroli College faculty, department coordinators, and management teams.

### Applications Included

* **StaffBridge:** Complete staff user documentation suite, covering onboarding, profile management, status lifecycles, and self-service dashboard usage.

### Current Documentation Coverage

1. **Help Center Foundation:** Landing Page, About JyotOS, and Help Center Support Navigation.
2. **Documentation Standards:** Architectural Design System (**JDDS-001**) detailing writing guidelines, accessibility standards, visual rules, and reusable templates.
3. **Staff User Guides:**
   * StaffBridge Overview
   * Getting Started with StaffBridge
   * Complete Your Staff Onboarding
   * Personal & Employment Information
   * Photo & Signature Guidelines
   * Understanding Your Profile Status
   * Responding to Correction Requests
   * Using Your Staff Dashboard

***

## Known Limitations (v0.1)

* **UI Screenshots:** User guides currently feature standardized `📷 Screenshot Placeholder` blocks awaiting visual interface captures.
* **Administrator Guides:** Department Coordinator review queues and System Administrator verification workflows are undergoing final validation and will be released in Version 0.2.

***

## Next Planned Enhancements (v0.2 Roadmap)

* **Batch 3 Integration:** Adding dedicated Department Coordinator & System Administrator verification guides.
* **UI Image Asset Replacement:** Replacing screenshot placeholders with high-resolution, privacy-masked interface images.
* **Search Optimization:** Further expanding instant search keyword triggers.
