## Need Support?

Finding guidance in the Help Center is simple:

* **Browse Documentation:** Navigate through organized sections in the left sidebar to find topic-specific guides.
* **Search Documentation:** Press **Ctrl + K** (or **Cmd + K**) at any time to search topics, terms, or guide titles.
* **Follow Step-by-Step Guides:** Access structured walkthroughs with checklists and status reference guides.
* **Troubleshoot Common Issues:** Find user-safe resolutions for common login, verification, and status questions.
