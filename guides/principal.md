# Principal & Executive Leadership Guide for JyotOS

{% hint style="info" %}
**Quick Facts**
* **Audience:** Campus Principals, College Leadership, Institutional Trustees
* **Applies To:** JyotOS Ecosystem (Executive Governance & Oversight)
* **Scope:** Campus-wide operational metrics, executive approvals, and cross-department oversight
{% endhint %}

This guide summarizes executive governance capabilities and workflows for institutional leaders across the live applications of the JyotOS ecosystem.

---

## 1. JyotOS Central (Institutional Launcher)

JyotOS Central serves as the executive starting point for college operations:

* **Executive Access:** Access authorized institutional management tools from a single launcher using your official college Google account (`@amrolicollege.ac.in`).
* **Ecosystem Visibility:** View active applications deployed across the campus community.
* **Access Requests:** Request administrative provisioning for newly introduced ecosystem services.

→ See [Central Overview](../products/central/overview.md).

---

## 2. StaffBridge (Institutional Roster & Verification)

StaffBridge maintains verified institutional staff records across all campus departments:

* **Campus Roster Visibility:** Monitor institutional onboarding progress across faculty, administrative, and technical cadres.
* **Verification Pipeline Oversight:** Review the count of profiles advancing through Coordinator Verified and Admin Verified stages.
* **Institutional Credential Records:** Reference officially established Ready profiles and assigned staff identification numbers.

→ See [StaffBridge Overview](../products/staffbridge/overview.md) and [StaffBridge Administrator Guide](../products/staffbridge/administrator-guide.md).

---

## 3. EventOS (Campus Event Governance)

EventOS centralizes event approvals and institutional calendar governance:

* **Executive Approval Queue:** Review event proposals submitted by department coordinators and committee conveners.
* **Proposal Evaluation:** Inspect proposed schedules, multi-day itineraries, campus venue allocations (Amroli Campus or Chaprabhatha Campus), and target participant capacity.
* **Approval Actions:** Grant executive approval to publish events to the campus community, or return proposals with written guidance for modifications.
* **Event Oversight:** Monitor published campus events across all academic and co-curricular domains.

{% hint style="warning" %}
**Coming soon:** Campus-wide attendance summaries, post-event reporting compilation, and automated analytics exports are not available yet.
{% endhint %}

→ See [EventOS Principal Guide](../products/eventos/principal-guide.md).

---

## 4. ClassPulse Pro (Academic Operations & Delivery)

ClassPulse Pro delivers campus-wide academic delivery monitoring across all departments:

* **Campus Academic Center:** Monitor institutional lecture delivery benchmarks across departments (BCA, BBA, B.Com).
* **Delivery Rate KPI:** Track campus-wide performance against the 85% lecture delivery target.
* **Faculty Lecture Reconciler:** Access institution-wide lecture reconciliation to review contracted teaching loads, conducted lectures, and delivery variances.
* **Diary & Timetable Inspection:** Review detailed teacher diary entries, timetable matches, and syllabus topic logs for any faculty member.

{% hint style="warning" %}
**Coming soon:** Single sign-on with JyotOS via StaffBridge launcher is not switched on yet for ClassPulse Pro. Institutional leaders access pilot tools using assigned credentials.
{% endhint %}

→ See [ClassPulse Pro Principal Executive View](../products/classpulse-pro/principal-executive-view.md) and [Faculty Lecture Reconciler](../products/classpulse-pro/faculty-lecture-reconciler.md).
