This guide explains common questions regarding profile review delays and status transitions.

***

## Profile Status Troubleshooting Table

| Status Situation                              | What It Indicates                                                  | Recommended Action                                                                                           |
| --------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **Status Remains 'Submitted'**                | Registration is in queue waiting for Department Coordinator review | Allow standard processing time. Contact Department Coordinator if pending over 3 business days.              |
| **Status Displays 'Needs Correction'**        | Field error flagged by reviewer                                    | Log into dashboard, view **Pending Correction Fields** section, update details, and click **Submit Update**. |
| **Status Displays 'Coordinator Verified'**    | Department approval complete; waiting for final Admin Verification | None required. Profile is advancing to final System Administrator approval.                                  |
| **Verified but Cannot Access Connected Apps** | Profile Status is Admin Verified, but Active Status is Inactive    | Contact System Administrator to request Active Status enablement.                                            |

***

## Active Status vs. Profile Status Distinction

Remember the key difference established in StaffBridge governance:

* **Profile Status:** Measures review lifecycle progress (**Submitted** ──► **Coordinator Verified** ──► **Admin Verified**).
* **Active Status:** Manages operational access enablement (**Active** / **Inactive**).
