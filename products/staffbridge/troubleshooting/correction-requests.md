# Troubleshoot Correction Requests

{% hint style="info" %}
**Quick Facts**
* **Audience:** Staff Members Responding to Correction Flags
* **Applies To:** StaffBridge Correction Workflows
* **Target Status:** Correction Submitted
{% endhint %}

This guide helps resolve issues when responding to field-level correction requests from department coordinators or system administrators.

---

## Common Correction Issues and Fixes

| Symptom | Likely Cause | Solution |
| :--- | :--- | :--- |
| **Reviewer Remark Unclear** | Remark instructions need additional context | Contact your Department Coordinator directly to clarify what needs updating before resubmitting. |
| **Field Appears Locked** | Attempting to edit a field not flagged for correction | Only fields specifically flagged by the reviewer can be edited during a correction cycle. Contact your coordinator if additional fields require changes. |
| **"Correction Submitted" Pending** | Resubmitted profile awaiting coordinator re-review | Coordinators typically re-review submissions within 1–2 business days. Contact your coordinator if urgent. |
| **Multiple Fields Flagged** | Several fields across sections require updates | Ensure you address every flagged field on your dashboard before clicking **Submit Update**. |

---

## Resolution Workflow

```
Read Reviewer Remarks ──► Update Flagged Fields on Dashboard ──► Submit Update ──► Coordinator Re-review
```

1. Review each flagged item and read the associated remark carefully.
2. Make the requested modifications only in the highlighted fields.
3. Click **Submit Update**.
4. Your profile status changes to **Correction Submitted** and returns to the review queue.
