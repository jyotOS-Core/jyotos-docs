# Troubleshoot Profile Status

{% hint style="info" %}
**Quick Facts**
* **Audience:** Staff Members Tracking Onboarding Status
* **Applies To:** StaffBridge Profile Tracking
* **Ready State:** Admin Verified with Active Status set to Active
{% endhint %}

This guide explains common questions regarding profile review timelines, status transitions, and ecosystem readiness.

---

## Status Situations and Recommended Actions

| Situation | Meaning | Recommended Action |
| :--- | :--- | :--- |
| **Status Remains "Submitted"** | Registration is in queue waiting for Department Coordinator review | Allow standard processing time (typically 1–3 business days). Contact your Department Coordinator if delayed. |
| **Status Displays "Needs Correction"** | A reviewer flagged one or more fields for update | Sign in to your dashboard, review the flagged fields and remarks, update the requested entries, and click **Submit Update**. |
| **Status Displays "Coordinator Verified"** | Department-level review is complete; awaiting final administrator approval | No action required from you. The record has advanced to the System Administrator queue. |
| **Verified but Cannot Access JyotOS Apps** | Profile Status is Admin Verified, but Active Status is Inactive | Contact your System Administrator to request Active Status enablement. |

---

## Profile Status vs. Active Status

Remember the distinction between the two status properties:

* **Profile Status:** Measures verification lifecycle progress (Submitted → Coordinator Verified → Admin Verified).
* **Active Status:** Governs whether your employee account is operational (`Active` / `Inactive`).

Both **Admin Verified** profile status and **Active** account status are required for an identity record to be **Ready** for single sign-on across JyotOS applications.
