# EventOS Troubleshooting

{% hint style="info" %}
**Quick Facts**
* **Audience:** Faculty, staff, department coordinators, principals, and administrators
* **Applies To:** EventOS Support & Diagnostics
* **Escalation Hierarchy:** Coordinator → Principal → System Administrator
{% endhint %}

This guide provides troubleshooting solutions for common issues encountered during sign-in, event registration, session attendance tracking, event proposal review, and post-event reporting.

---

## Sign-In and Access Issues

| Symptom | Likely Cause | Solution |
| :--- | :--- | :--- |
| **Google Sign-In Rejected** | Signed in with a personal Gmail account | Sign out of personal accounts and sign in using your college Google account ending in `@amrolicollege.ac.in`. |
| **Profile Not Found Notice** | StaffBridge onboarding incomplete or unverified | Complete onboarding in StaffBridge. Your profile must reach Admin Verified status to be eligible for EventOS single sign-on. |
| **"Account Inactive" Notice** | Account marked inactive in institutional settings | Contact your System Administrator to verify your employment status and reactivate your profile. |
| **Coordinator or Principal View Missing** | Role has not been assigned in EventOS | EventOS permissions are managed independently from StaffBridge. Contact your System Administrator to assign your role. |

---

## Registration Issues

| Symptom | Likely Cause | Solution |
| :--- | :--- | :--- |
| **"Not Eligible" Message** | Event restricted to other departments or campuses | Check the event eligibility criteria. If your department assignment is missing or incorrect, contact the System Administrator. |
| **"Registration Closed" Alert** | Registration window has expired or not yet opened | Review the registration schedule on the event details page. Registration is permitted only between the opening and closing times. |
| **"Capacity Full" Notice** | Event has reached maximum participant limit | If a waiting list is active, join the waiting list. You will be automatically enrolled if an existing participant cancels. |
| **Cannot Cancel Registration** | Registration window has closed | Self-service cancellation is disabled after the registration closing time or after attendance has been marked. |

---

## Session Attendance and QR Scanning Issues

| Symptom | Likely Cause | Solution |
| :--- | :--- | :--- |
| **Camera View Not Opening** | Browser camera permissions blocked on device | Open browser site settings, set **Camera** to **Allow**, and refresh the scanner page. |
| **QR Code Not Scanning** | Screen brightness too low or glare on display | Increase phone screen brightness and hold the device steady within the scanner frame. |
| **"Outside Attendance Window" Notice** | Attendance window not yet opened or has closed | The coordinator must open or extend the session attendance window before check-ins can be scanned. |
| **"Unmapped Scanner" Notice** | Helper assigned from a different campus | Helpers must belong to the same campus where the event is hosted. Check helper assignments in the coordinator workspace. |
| **Phone Battery Depleted at Venue** | Physical device unavailability | Request a manual check-in from the event coordinator by providing your name and reference ID. |

---

## Proposal and Approval Issues

| Symptom | Likely Cause | Solution |
| :--- | :--- | :--- |
| **Cannot Select Campus Venue** | Venue belongs to a different campus | EventOS enforces campus-level venue mapping. Select a venue located on the event's hosting campus. |
| **Proposal Returned for Changes** | Principal requested modifications | Open the proposal in the Coordinator Workspace, review the Principal's remarks, update the requested fields, and resubmit. |
| **Revised Event Shows Old Details** | New revision still pending Principal approval | The earlier approved event version remains active and visible until the Principal reviews and approves the revision. |

---

## Report Package Issues

| Symptom | Likely Cause | Solution |
| :--- | :--- | :--- |
| **Cannot Submit Report Package** | Mandatory fields missing (e.g., press note) | Ensure all required fields are complete: narrative summary, section highlights, participant counts, photo captions, and press note. |
| **Photo Upload Rejected** | File format unsupported or size exceeds limits | Upload images in standard JPEG or PNG format under 5 MB per photograph. |
| **Report Status Shows "Sent Back"** | Principal requested report revisions | Open the report package in the Coordinator Workspace, read the feedback comments, update the text or media, and resubmit. |

---

## Support Escalation

If your issue remains unresolved after following these troubleshooting steps, escalate through the established institutional hierarchy:

```
Participant ──► Event Coordinator ──► Campus Principal ──► System Administrator
```

* **Participants:** Reach out to the organizing Department Coordinator for eligibility and attendance queries.
* **Coordinators:** Contact your campus Principal for proposal and schedule questions, or the System Administrator for venue and role setup.
